# Malik Fardhana Portfolio

Minimal black & white portfolio landing page built with vanilla HTML, CSS, and JavaScript.

## Files

- `index.html`
- `css/style.css`
- `css/responsive.css`
- `js/main.js`
- `assets/images/projects/` — replace project placeholder SVGs here
- `assets/images/profile/profile-placeholder.svg` — replace with Malik's photo
- `assets/documents/malik-fardhana-cv.pdf` — replace placeholder PDF with the real CV

## How to replace images

You can either:

1. Keep the existing filenames and overwrite the placeholder files, or
2. Change the `src=""` path inside `index.html`.

Recommended formats:
- Project hero image: 16:9 or roughly 1920×1040
- Square/detail images: 1:1 or 4:3
- Portrait: 4:5

## Run locally

Open `index.html` directly in your browser.

For a better local development workflow, use VS Code + Live Server.

## GitHub Pages

1. Create a GitHub repository.
2. Upload all files while preserving the folder structure.
3. Open repository Settings → Pages.
4. Choose `Deploy from a branch`.
5. Select `main` branch and `/root`.
6. Save.
